# SocialDev

A social media app for developers — create, edit, delete, and sort posts. Built with React, Vite, and Tailwind CSS.

## Features

- Create posts
- Edit existing posts
- Delete posts
- Sort posts newest → oldest or oldest → newest

## Tech Stack

- React
- Vite
- Tailwind


1. Clone the repository


git clone https://github.com/magobryan81/social-media-app.git


2. Install dependencies

   # Styling
  npm install tailwindcss @tailwindcss/vite
  
  # Date formatting
  npm install date-fns
  
  # Icons
  npm install lucide-react
   

3. Run the development server

   npm run dev
   
4. Open the app

   Visit [http://localhost:5173]
